# Emoji Launcher

Lightweight Emoji Picker for Linux, Windows and MacOS.

![Screenshot.png](promo/Screenshot.png)

This project was developed for Ubuntu, and should work on any device supporting OpenGL 3.3.

The emojis are from [Twemoji](https://github.com/twitter/twemoji),
and the names for filtering have been taken from [Unicode.com](https://unicode.org/Public/emoji/latest/).

Used libraries: LWJGL (GLFW + OpenGL).

## Install
This application only is the launcher itself. It doesn't launch itself.
To use this on Ubuntu, define a custom shortcut with the command 'java -jar path/to/EmojiLauncher.jar'.

For Windows/MacOS, I don't know, Google it yourself, please.

## Controls
Use your mouse (move + click) or your arrow keys (+ enter) to choose an emoji to paste.
Use the arrow keys or your mouse wheel to scroll. You can also press and drag to scroll.

Use F1 to toggle between light and dark mode. If you select light mode, there is a file called UseLightTheme.txt.
